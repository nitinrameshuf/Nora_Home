Docker Compose brought up MySQL, Mongo, Redis, RabbitMQ and MinIO cleanly on a real Raspberry Pi 5, and the 24" wall and 10.1" touchscreen kiosk both render real app content, authenticated, with the kiosk driving the wall as a context- sensitive remote control. Decisions taken, and why

Django, not FastAPI or Node

The admin alone justifies it: a family member can retime a job or edit an escalation ladder without a deploy. Batteries-included matters more than raw throughput on a home LAN. Settled.

Web app in kiosk mode, not a native app

One codebase covers the 24" wall, the 10.1" kiosk, phones, iPads and laptops. Chromium --kiosk is the full-screen app experience, and updates are make deploy with no app store or version skew. The one real gap is iOS background push — which is precisely why notifications were built channel-agnostic, with Slack covering urgency. Settled.

MySQL and MongoDB, both

Anything the tracker joins across is relational and belongs in MySQL. Journals, AI transcripts and raw integration payloads change shape as ideas change, and belong in Mongo. Mongo is optional — its absence is degraded, not broken. Settled.

RabbitMQ for work, Redis for everything else

Durable queues and real routing mean a runaway house-app task can never delay an escalation. Redis is cache, Channels layer and rate limits. One env flag collapses both to Redis for laptop work. Settled.

Occurrences materialized, not computed

The tracker writes concrete rows two weeks ahead. That is what makes "what did I miss last March" answerable and gives escalation state somewhere to live. Settled.

Escalation policies are data, not code

EscalationPolicy.levels is JSON edited in the admin. The house can change how hard it pushes without a developer. Settled.

Apps mount at the URL root

/workout, /family, /maintenance — each reads like its own site. The platform lives under /home, and a reserved-slug guard stops an app claiming a platform prefix. Settled (changed from /app/<slug>/).

Widgets return data, not HTML

ChartWidget.option() returns an ECharts option dict and the platform applies colour, type and dark/light. This is the single reason a chart written by one family member looks like one written by another. Settled.

Vendored libraries, no build step

ECharts and Gridstack are committed to the repo. The house must render with the internet down, the Pi must never run a bundler, and a CDN outage must not blank the wall display. Settled.

Secrets never enter the database

Integration credentials are read from the environment via Integration.secret(). A database dump shared for debugging carries no tokens. Settled.

Nora Home is not Nora

The robot is a separate machine with its own repository. Package, settings prefix, CSS classes and JS globals were all renamed to nora_home / NORA_HOME_* / nh- so the two can never be confused in an import or a system prompt. They meet at exactly two places. Settled 2026-07-31.

Design language: "Almanac"

Two dashboard-shaped rounds rejected as generic regardless of palette; an ambient/passive-wall idea was tried and rejected too. Landed on a living background — real season, time of day, and outside weather composited behind the actual, fully-interactive app. "Charm outside, polish inside." Decided and shipped 2026-08-03 — engine only, full component restyle still ahead.
